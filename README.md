# MasterChef AI

MasterChef AI is an AI-powered Smart Cooking Recommendation and Nutrition Assistant built using Streamlit, Python, and Gemini AI.

## Features

- Personalized Dish Recommendation
- Recipe Viewer
- Beautiful Multi-Theme UI
- AI Cooking Assistant
- Nutrition Expert Escalation (HITL)
- Gemini AI + Smart Fallback Responses

## Tech Stack

- Python
- Streamlit
- Pandas
- Gemini AI
- Google Generative AI
- HTML/CSS Styling

## Project Type

AI + Data Science + Recommendation System + HITL + GenAI
